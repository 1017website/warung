Panduan POS Warung
per menu dan hak akses

Pilih role Anda. Setiap panduan memuat menu yang dapat dibuka, urutan kerja, hasil yang diharapkan, batas otorisasi, dan screenshot setelah perbaikan.

Format HTML dapat dibaca offline melalui folder ini. Gunakan Cetak / Simpan PDF di masing-masing panduan bila ingin membuat salinan cetak.

Superadmin

Mengelola operasional, role, akun level bawah, dan konfigurasi. Pemeliharaan tersedia hanya selama belum ada akun Developer aktif dalam tenant.

Head of Ops

Mengawasi operasional lintas cabang dan laporan riil. Pengaturan dan laporan non-riil tidak tersedia pada akses bawaan.

9 menu · Seluruh cabang

Buka panduan Head of Ops → · Markdown

Ops Admin

Mengelola operasional, produk dan pembelian. Memerlukan PIN pejabat berwenang untuk aksi otorisasi; tidak memiliki Ringkasan, Laporan, atau Pengaturan.

7 menu · Cabang akun

Buka panduan Ops Admin → · Markdown

Outlet Manager

Menangani operasional outlet dan otorisasi. Stok awal tidak dapat diedit. Ringkasan, Produk, Pembelian, Laporan, dan Pengaturan tidak tersedia pada akses bawaan.

5 menu · Cabang akun

Buka panduan Outlet Manager → · Markdown

SPV

Mengawasi transaksi, stok, member, dan rekonsiliasi cabang serta memberikan otorisasi sesuai PIN. Tidak dapat mengoreksi stok awal.

5 menu · Cabang akun

Buka panduan SPV → · Markdown

Kasir

Menjalankan operasional cabang. Minta otorisasi pejabat berwenang untuk transaksi pengganti, pembatalan lewat 30 detik, koreksi deposit, dan tutup kasir.

Role khusus mengikuti master role, bukan daftar nama role bawaan. Sub-akses Pengaturan diberikan terpisah; pengelolaan role/akun tetap dibatasi pada akun sistem yang berwenang. Membership dapat dipakai lintas cabang dalam tenant yang sama.

Label operasional “tanpa omzet” berarti tidak memiliki Ringkasan/Laporan; nominal transaksi dan rekap kas tetap dapat dilihat melalui menu operasional yang diberikan.
